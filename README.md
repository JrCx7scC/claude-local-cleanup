# 清理这台电脑上的 Claude

把下面这一句原样发给你自己的 AI。它会先只读检查，把这台电脑上**会删掉的内容**列出来。你同意之前，它不会删除。

```
读取并遵守 https://raw.githubusercontent.com/JrCx7scC/claude-local-cleanup/main/SKILL.md 。先只做只读检查，把会删掉的内容列给我，我同意之前不要删除。
```

适用系统：Windows 10 / 11，macOS。命令行版和桌面版都算。仓库里没有脚本。不要让 AI 下载或运行别人的清理程序。

最后更新：2026-11-25。

## 清单里不只有聊天记录

AI 只能报告这台电脑上真实存在的文件，并写清每一项里面是什么、删了会怎样、哪一档才会删。

- **只清登录**就会动：登录凭据、桌面版登录态、这台安装的设备标识、额度缓存、桌面版缓存和日志。命令行保存的账户信息和 MCP 列表、桌面版里亲手写的加密配置、插件授权也会动。本机聊天记录留下。
- **连聊天记录一起清**再动：本机对话、输入历史、附件、Cowork 工作文件。云端对话不动。
- **彻底**再动：卸载程序，删掉探测到的整份数据目录。聊天记录一定在里面。你写的 skills、插件、`CLAUDE.md`、设置也会没，除非你事先说要留。

要留聊天记录，就只选第一档。

看完清单后用一句话回复，例如「只清登录，聊天记录留下」。没回复，它就停。

## 做不到的

- 不能改变封号结果。本机清理只解决串号和隐私。
- 不能删除 claude.ai 上的记录。
- 不能退出其他电脑和手机上的登录。那些要到 claude.ai → Settings → Security 里逐个撤销。

公司或学校发的电脑，先把清单给管理员。

做完后 AI 可以交一张回执：系统、版本、删了哪些路径、留了哪些、报错原文。不要让它附上任何文件内容。
